## General
- Use simple, plain english when explaining or asking questions.

## Hygene
- Delete branches after merge
- Use [Conventional Commits 1.0.0](./docs/reference/conventional-commits-1.0.0.md).

## Tooling
- When ripgrep (`rg`) is available, use it over regular `grep`.
- When search and displace (`sd`) is available, use it over `sed`.

## Building
- Use the [10 design principles for delightful CLIs](./docs/cli-design-principles.md) document to guide your work.
- Acceptance tests are key to trusting the delivered code which is why we need have a comprehensive acceptance test suite which include all edge cases.
